# MMORPG_MAPS

Criação de mapas para um jogo em Godot desenvolvido em outro projeto.
Cada mapa é entregue como um pacote .zip para ser integrado ao jogo.

- `visualizador/` — projeto Godot usado para ver e andar pelos mapas (exportado para web).
- Visualização online: https://mmorpgclaude.github.io/MMORPG_MAPS/
